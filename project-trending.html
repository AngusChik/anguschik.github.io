Problem

YouTube's native trending page mixes Shorts, stale videos, and sponsored content into a single feed with no way to filter by category or understand why something is trending — the signal is buried in noise.

Process

  • Built a custom scoring algorithm using view velocity, engagement rate, and recency — capped at 168 hours
  • Added Shorts detection by duration and hashtag to exclude them from results
  • Exposed a category-filtered API via Express, backed by a 15-minute response cache

Learnings

A score is only as useful as its inputs are clean. Getting Shorts detection right — accounting for YouTube's extended 3-minute limit and hashtag requirement — made the difference between a feed that felt curated and one that still felt polluted.

06 Web App 2024

A YouTube trending feed rebuilt around a custom scoring algorithm — filtering by category, velocity, and engagement with a paired Chrome extension.

An Express server queries the YouTube Data API v3, scores each video by a velocity-and-engagement formula, strips out Shorts, and serves a filtered feed by category. A Chrome extension popup connects to the server so trending results are accessible directly from the browser toolbar without leaving the current tab.

Outcome

A cleaner, more honest trending feed — category-aware, Shorts-free, and sorted by actual momentum.
