Problem

Editorial portfolios often prioritise visual flair over readability — the challenge was building a framework that kept reading comfortable while still feeling designed.

Process

  • Set the type scale using a modular ratio tied to the base reading size
  • Introduced deliberate whitespace zones between sections as structural elements
  • Tested long-form content against the layout to catch rhythm breaks early

Learnings

Whitespace is not empty — it carries pacing. The most effective changes were removals: pulling back line density and widening margins had more impact than any typeface swap.

An editorial portfolio framework shaped around rhythm, contrast, and just enough structure to let the content breathe.

The framework needed to carry dense long-form writing without feeling heavy. Decisions were driven by reading comfort first — type scale, measure, and whitespace were locked in before any visual personality was introduced, ensuring the structure held under real content conditions.

Deliverables

  • Page structure & grid system
  • Type hierarchy rules
  • Component library
  • Content pacing guidelines

Outcome

A portfolio system that feels spacious and deliberate.
