Problem

Manually skipping YouTube sponsor segments is repetitive and interrupts viewing. V1 explored automating this by querying an existing crowd-sourced API and mapping its timestamp data to the YouTube player.

Process

  • Queried the SponsorBlock API to fetch segment timestamps per video ID
  • Injected a content script to monitor playback position and trigger skips
  • Built a popup UI for toggling the extension and viewing segment data

Learnings

Working with a live DOM from a content script is fragile. YouTube's dynamic single-page rendering meant the player could reload without a full navigation — catching those state changes reliably required careful event handling and retry logic.

08 Extension 2024

A Chrome extension that skips YouTube sponsor segments by querying the SponsorBlock API and mapping timestamps to the video player.

On page load, the extension fetches sponsor segment data from the SponsorBlock API using the current video ID. A content script monitors the player's current time and seeks past any flagged segments automatically. The popup provides a simple toggle and live segment count for the active video.

Outcome

A working V1 that proved the concept and exposed the limitations of relying on external data — leading directly to V2.
