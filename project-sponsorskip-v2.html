Problem

V1 depended entirely on a third-party crowd-sourced database. V2 needed to detect sponsor segments independently — without external data — using pattern recognition on video transcripts.

Process

  • Built a transcript extraction pipeline and labelled training data for sponsor detection
  • Trained and iterated on a classification model, testing against regression cases
  • Bundled via webpack into a production-ready Manifest V3 Chrome extension

Learnings

Training data quality mattered more than model complexity. Short transcript windows are noisy — cleaning and consistently labelling the data had a larger impact on detection accuracy than any architectural change to the model.

05 Extension 2025

A Chrome extension that uses a trained ML model to detect and skip YouTube sponsor segments — no crowd-sourced database required.

The extension extracts captions from YouTube, runs them through a trained classifier to identify sponsor windows, and automatically skips those segments during playback. Built on Manifest V3 with a service worker background script, webpack bundling, and a popup UI for settings and status.

Outcome

A self-contained sponsor detection system that works without any external API dependency.
